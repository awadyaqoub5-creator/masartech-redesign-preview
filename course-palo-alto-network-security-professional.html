وصف دورة Palo Alto Network Security Professional

برنامج تدريبي مهني يهيئك لفهم حلول Palo Alto Networks ضمن منصة Network Security، وكيف تتكامل الجدران النارية من الجيل التالي، Prisma SASE، الإدارة المركزية، والخدمات الأمنية السحابية لحماية شبكات المؤسسة.

تركز الدورة على المعرفة العملية المناسبة للمستوى Professional: فهم حالات الاستخدام، اختيار الحل المناسب، قراءة منطق السياسات الأمنية، استيعاب خيارات الإدارة والمراقبة، والتعامل مع مفاهيم التهيئة والصيانة والنشر الأساسي. الهدف ليس حفظ أسماء المنتجات، بل فهم موقع كل مكوّن داخل بنية أمن الشبكات.

المخطط الرسمي الصادر في يونيو 2026 وسّع نطاق الشهادة ليشمل موضوعات حديثة مثل Strata Cloud Manager، Cloud-Delivered Security Services، مخاطر الذكاء الاصطناعي، الاستعداد للتشفير ما بعد الكمي، وNext-Generation Trust Security. لذلك تم تحديث المحتوى بدل الاعتماد على وصف قديم يقتصر على NGFW وSASE بصورة عامة.

تمييز ضروري: دورة مسارتك تدريب تحضيري وتطبيقي يمنح شهادة حضور وفق سياسة المعهد. شهادة Palo Alto Networks الرسمية لا تُمنح بالحضور؛ يجب حجز الاختبار الرسمي واجتيازه عبر الجهة المعتمدة.

ما هي شهادة Network Security Professional؟

هي شهادة رسمية حالية من Palo Alto Networks على مستوى Professional ضمن منصة Network Security. تتحقق من فهم المنتجات والخدمات التي تدخل في حل أمن الشبكات، وحالات استخدامها داخل المؤسسة، مع القدرة على الاستخدام والصيانة والتهيئة على مستوى ابتدائي وتنفيذ التثبيت والنشر الأساسي.

Next-Generation Firewalls

فهم أدوار PA-Series وVM-Series وCN-Series وCloud NGFW والسياسات والتجزئة والمراقبة.

Prisma SASE

فهم Prisma Access وPrisma SD-WAN وحماية المستخدمين والفروع والتطبيقات.

Cloud-Delivered Security

التعرف على Advanced Threat Prevention وWildFire وURL Filtering وDNS Security وDLP وغيرها.

الإدارة المركزية

فهم دور Panorama وStrata Cloud Manager في الإدارة والتقارير ومتابعة الإعدادات.

لغة الاختبار: يوضح مخطط يونيو 2026 أن الاختبارات تُقدَّم عالميًا باللغة الإنجليزية، مع تمديد افتراضي قدره 30 دقيقة للمتقدمين في الدول غير الناطقة بالإنجليزية. تفاصيل الحجز والسياسات قد تتغير، لذلك تُراجع رسميًا قبل الدفع.

  • أنشئ حسابك واحجز موعد الاختبار عبر القناة الرسمية التي تحددها Palo Alto Networks.
  • تحقق من أن قسيمة الاختبار غير مشمولة في سعر الدورة إلا إذا نص العرض على ذلك صراحة.

الأسئلة الشائعة عن دورة Palo Alto Network Security Professional

هل Network Security Professional شهادة رسمية حالية؟

نعم. هي شهادة رسمية حالية من Palo Alto Networks على مستوى Professional ضمن منصة Network Security.

هل الدورة تركز على PAN-OS وFirewall فقط؟

لا. تشمل الشهادة محفظة أوسع تضم NGFW وPrisma SASE وCloud-Delivered Security Services وPanorama وStrata Cloud Manager وحالات الاستخدام المرتبطة بها.

هل أحتاج CCNA قبل الدورة؟

لا يشترط امتلاك الشهادة، لكن تحتاج معرفة عملية بأساسيات TCP/IP وRouting وNAT وVPN وسياسات الجدران النارية. يمكن دراسة CCNA أو Network+ عند ضعف الأساس.

هل الدورة مناسبة للمبتدئ تمامًا في الأمن السيبراني؟

ليست أفضل بداية لمن لا يعرف الشبكات. ابدأ بأساس الشبكات ثم Security+ عند الحاجة، وبعدها تصبح مفاهيم Palo Alto أكثر وضوحًا.

ما الفرق بين Network Security Professional وNGFW Engineer؟

Professional شهادة واسعة لفهم محفظة Network Security والتشغيل الأساسي، بينما Next-Generation Firewall Engineer تخصص أعمق في نشر وإدارة PAN-OS والجدران النارية والتكامل وPanorama.

ما أهم جزء في مخطط الاختبار الحالي؟

مجال Platform Solutions, Services, and Tools هو الأكبر بوزن 30%، يليه Network Security Fundamentals وInfrastructure Management and CDSS بوزن 17% لكل منهما.

هل دخلت موضوعات AI والتشفير ما بعد الكمي في الشهادة؟

نعم، مخطط يونيو 2026 يتضمن مخاطر أمن الذكاء الاصطناعي وطرق الحد منها، إضافة إلى مخاطر التشفير الكمي واستعداد المنصة لما بعد الكم.

ما لغة الاختبار الرسمي؟

ينص مخطط يونيو 2026 على تقديم الاختبارات عالميًا باللغة الإنجليزية، مع تمديد افتراضي 30 دقيقة في الدول غير الناطقة بالإنجليزية. راجع السياسة الرسمية قبل الحجز.

هل شهادة حضور مسارتك هي شهادة Palo Alto الرسمية؟

لا. شهادة الحضور تثبت إكمال البرنامج التدريبي لدى المعهد، أما اعتماد Palo Alto Networks فيتطلب حجز الاختبار الرسمي واجتيازه.

هل رسوم الاختبار الرسمي ضمن سعر الدورة؟

لا تفترض ذلك. السعر المذكور يخص التدريب، وتكون القسيمة مشمولة فقط إذا ذُكرت صراحة في عرض التسجيل.

هل الدورة أونلاين أم حضورية؟

تتوفر أونلاين مباشر بسعر 1,150 ريال أو حضوريًا في الرياض بسعر 1,450 ريال، وفق مواعيد الدفعات والمقاعد المتاحة.

ما الشهادة الأنسب بعد هذه الدورة؟

يعتمد الاختيار على الدور: Network Security Analyst للإدارة والسياسات، NGFW Engineer للجدران النارية، SD-WAN Engineer للاتصال، Security Service Edge Engineer لـSSE/SASE، أو Network Security Architect للتصميم المعماري.
