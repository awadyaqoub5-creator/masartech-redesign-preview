دورة Power BI أونلاين أو حضوري بالرياض

اختر طريقة التدريب المناسبة لك. الزر يحاول اختيار نوع الحضور نفسه داخل نموذج الحجز ثم ينقلك إليه، وعند تغير الدفعة يتحدث السعر الظاهر في هذه الصفحة من بيانات الحجز.

Power BI أونلاين مباشر

لمن يريد التدريب عن بعد مع الدفعة المتاحة

  • مناسب للمتدرب خارج الرياض أو من يفضل التعلم عن بعد.
  • المواعيد والأيام الفعلية تتبع الدفعة المفتوحة في الحجز.
  • تأكد من جاهزية جهاز Windows وبيئة Power BI المطلوبة قبل البداية.

Power BI حضوري بالرياض

تدريب داخل مقر المعهد حسب الدفعة المتاحة

  • مناسب لمن يفضل التفاعل داخل قاعة التدريب.
  • الموعد والسعر النهائي يتبعان الخيار المختار في نموذج الحجز.
  • لا نفترض أن كل دفعة لها نفس الأيام أو نفس العرض السعري.

Power BI Desktop وService وMicrosoft Fabric: ما الفرق؟

Power BI Desktop

بيئة Windows الأساسية لبناء نماذج البيانات وكتابة DAX وتصميم التقارير.

Power BI Service

البيئة السحابية للنشر والتعاون وإدارة المحتوى والتحديث والصلاحيات حسب الترخيص.

Microsoft Fabric

منصة تحليل أوسع تضم Power BI ضمن منظومة أكبر؛ نغطي فقط ما يرتبط فعليًا باستخدام Power BI وأهداف PL-300.

مهم قبل التسجيل: بعض ميزات المشاركة وCopilot تعتمد على نوع الترخيص والسعة والحساب المستخدم. لا يعني التدريب على Power BI أن جميع خدمات Pro أو Fabric أو Copilot متاحة تلقائيًا بحساب مجاني.

Excel أم Power BI: أيهما تحتاج أولًا؟

Excel وPower BI متكاملان، وليس من الدقة اعتبار أحدهما بديلًا مطلقًا للآخر.

دورات تكمل مسارك في تحليل البيانات

تحليل البيانات باستخدام Excel لتقوية الأساس في الجداول والتحليل قبل أو بجانب Power BI. تحليل البيانات باستخدام Python لمن يريد التوسع في التحليل والبرمجة والأتمتة. IIBA-CBDA لربط تحليل البيانات بتحليل الأعمال وصنع القرار. CDMP للتوسع في إدارة البيانات والحوكمة داخل المؤسسات. دورة PMP لمن يجمع بين التقارير والتحليل وإدارة المشاريع. جدول التدريب راجع الدفعات والمواعيد المتاحة قبل التسجيل.

الأسئلة الشائعة عن دورة Power BI لتحليل البيانات وPL-300

هل دورة Power BI مناسبة للمبتدئين؟

يمكن للمبتدئ بدء تعلم Power BI، ويفيده وجود أساس في الجداول والبيانات. أما الاستعداد لاختبار PL-300 فمستواه Intermediate ويحتاج ممارسة وفهمًا للمجالات المقاسة، وليس مجرد حضور الدروس.

هل أحتاج Excel قبل تعلم Power BI؟

ليس شرطًا أن تشتري دورة Excel أولًا، لكن فهم الجداول والبيانات وPivotTables يساعد. إذا كان أساسك ضعيفًا جدًا في البيانات فقد يكون التأسيس في Excel مفيدًا قبل التوسع.

هل دورة Power BI معتمدة؟

التدريب يقدمه معهد مسارتك وفق ترخيصه وسياسة البرنامج، بينما شهادة Microsoft الدولية المرتبطة بالمسار هي Microsoft Certified: Power BI Data Analyst Associate وتحصل عليها بعد اجتياز اختبار PL-300. شهادة حضور التدريب منفصلة عنها.

هل أحصل على شهادة Power BI من Microsoft بعد الدورة مباشرة؟

لا. إتمام الدورة لا يمنح شهادة Microsoft تلقائيًا. يلزم حجز اختبار PL-300 الرسمي واجتيازه للحصول على الشهادة الدولية.

ما مدة اختبار PL-300؟ وهل هو متاح بالعربية؟

مدة التقييم المنشورة حاليًا 100 دقيقة. العربية ليست ضمن لغات الاختبار المدرجة في صفحة Microsoft الحالية، لذلك افصل بين لغة التدريب ولغة الاختبار.

هل رسوم اختبار PL-300 ضمن سعر الدورة؟

لا تعتبر رسوم الاختبار أو القسيمة جزءًا من سعر التدريب تلقائيًا. إذا شمل عرض دفعة معينة Voucher أو خدمة اختبار فيجب أن يظهر ذلك صراحة في تفاصيل العرض.

هل Power BI يحتاج برمجة؟

يمكن البدء عبر الواجهة وPower Query دون خلفية برمجية تقليدية، لكن الاستخدام الاحترافي يتطلب تعلم DAX للحسابات وفهم النمذجة بدل الاعتماد على السحب والإفلات فقط.

ما الفرق بين Power BI Desktop وPower BI Service؟

Desktop هو تطبيق Windows المستخدم لبناء النماذج والتقارير، بينما Service هو البيئة السحابية للنشر والتعاون والتحديث وإدارة المحتوى والصلاحيات حسب الترخيص.

هل أحتاج Power BI Pro أو Microsoft Fabric؟

يعتمد ذلك على التمارين والمشاركة والخدمات التي ستستخدمها. بعض خصائص النشر والتعاون وCopilot تعتمد على نوع الترخيص والسعة؛ لذلك راجع متطلبات الدفعة قبل التسجيل.

ما الوظائف التي تستفيد من Power BI؟

تدخل مهارات Power BI في أعمال Data Analyst وBI Analyst وReporting Specialist وبعض أدوار المالية والتسويق والموارد البشرية وتحليل الأعمال، لكن الدورة وحدها لا تضمن مسمى وظيفيًا.
