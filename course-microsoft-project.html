وصف دورة Microsoft Project

برنامج تدريبي عملي يركز على تطبيق Microsoft Project Desktop في تخطيط وجدولة ومتابعة مشروع واحد بصورة منهجية، من تعريف التقويم وهيكلة العمل حتى تسجيل التقدم وإصدار تقارير الحالة.

تتعلم كيف تتحول المراحل والأعمال إلى مهام قابلة للجدولة، وكيف تؤثر العلاقات والقيود والتقويمات في تاريخ الانتهاء، وكيف تكشف الموارد المحمّلة فوق طاقتها، ثم كيف تحفظ الخطة الأصلية وتقارنها بالواقع بدل تحديث التواريخ عشوائيًا.

ما هو Microsoft Project؟

Microsoft Project Desktop هو تطبيق متخصص لإنشاء خطط المشاريع وفرق العمل وتخصيص الموارد وعرض المهام والموارد وقياس التقدم وإدارة الميزانيات، ويستخدم ملف MPP كصيغة أساسية لخطة المشروع.

في 2026 يجب التمييز بين منتجات تحمل أسماء متقاربة: تطبيق Project لسطح المكتب ما زال متاحًا ومدعومًا، بما في ذلك إصدارات Project Standard 2024 وProject Professional 2024؛ بينما تم إيقاف Project for the web في أغسطس 2025 وانتقلت تجربته إلى Microsoft Planner.

الأداةمتى تستخدمها؟نقطة القوةما الذي تنتبه له؟
Microsoft Project Desktopعند الحاجة إلى جدول تفصيلي وعلاقات وقيود وموارد وخط أساس.عمق الجدولة والتحكم في الخطة وملفات MPP.تحتاج نسخة مناسبة على Windows وفهمًا جيدًا لمنطق الجدولة.
Microsoft Plannerلإدارة عمل الفرق والخطط الأساسية والمميزة والتعاون داخل Microsoft 365.سهولة التعاون وتوحيد تجربة Planner وProject for the web السابقة.الواجهة والخصائص تختلف عن Project Desktop، فلا تخلط بين التدريبين.

الاختبار والشهادة

Microsoft Project ليس منهجية لإدارة المشاريع ولا شهادة مهنية، والدورة تدريب عملي على الأداة. شهادة الإتمام هي شهادة حضور وفق سياسة المعهد، ولا تُعد شهادة Microsoft رسمية ما لم يوجد اعتماد مكتوب محدد.

يُقاس ما تتعلمه بقدرتك على بناء ملف مشروع يمكن تدقيق منطقه وتحديثه وشرح نتائجه. يؤكد فريق مسارتك نوع الشهادة المقدَّمة عند التسجيل.

  • اسأل قبل التسجيل عن إصدار Project Desktop المستخدم ومتطلبات الجهاز وعدد الساعات.
  • نفّذ المشروع التطبيقي من ملف فارغ حتى حفظ Baseline وتحديث التنفيذ وإصدار تقرير الحالة.
  • راجع مع المدرب منطق الجدولة والمسار الحرج والموارد في ملفك قبل اعتماده.
  • استلم شهادة الحضور وفق سياسة المعهد بعد إتمام البرنامج.
  • إذا كان هدفك شهادة مهنية في إدارة المشاريع، فاسأل عن مسارات مثل CAPM أو PMP.

تركز الصفحة على Microsoft Project Desktop وإدارة ملفات MPP. انتهت تجربة Project for the web في أغسطس 2025 وانتقلت إلى Microsoft Planner، لذلك يجب تأكيد إصدار البرنامج المستخدم في التدريب قبل التسجيل.

ما الفرق بين Microsoft Project وMicrosoft Planner؟

Microsoft Project Desktop أعمق في الجدولة التفصيلية والعلاقات والقيود والموارد وخطوط الأساس، بينما يركز Planner على إدارة العمل والتعاون وخطط الفرق، ويضم حاليًا الخطط الأساسية والمميزة التي انتقلت من Project for the web.

ما الفرق بين Microsoft Project وExcel؟

Excel مرن للجداول والتحليل والحسابات، لكنه لا يدير منطق الجدول الزمني تلقائيًا مثل العلاقات بين المهام والمسار الحرج والقيود وتسوية الموارد. يستخدم كثير من الفرق الأداتين معًا بدل اعتبار إحداهما بديلًا كاملًا للأخرى.

هل الدورة تمنح شهادة Microsoft رسمية؟

الدورة تمنح تدريبًا وشهادة حضور وفق سياسة معهد مسارتك. لا تُعد شهادة حضور المعهد اعتمادًا مهنيًا صادرًا من Microsoft، ولا يوجد في هذه الصفحة ادعاء بوجود اختبار Microsoft رسمي مخصص لإتمام الدورة.

هل تتضمن الدورة رخصة Microsoft Project؟

لا تُعد رخصة البرنامج مشمولة تلقائيًا في رسوم التدريب ما لم يذكر ذلك كتابةً في عرض التسجيل. يجب التأكد من توفر نسخة Project Desktop المناسبة على جهاز التدريب أو الجهاز الشخصي.

هل Microsoft Project يغني عن دراسة PMP؟

لا. Microsoft Project أداة للجدولة والمتابعة وإدارة بيانات المشروع، بينما PMP يغطي منهجيات وممارسات إدارة المشروع والقيادة والمخاطر وأصحاب المصلحة. تعلم الأداة يكمل المعرفة الإدارية ولا يستبدلها.

هل تشمل الدورة المسار الحرج وBaseline ومتابعة الانحرافات؟

نعم، يتضمن المحتوى المقترح بناء العلاقات، قراءة Critical Path وTotal Slack، حفظ Baseline، إدخال التقدم الفعلي، واستخدام Variance لمقارنة الخطة بالتنفيذ.

كم سعر دورة Microsoft Project؟

السعر المبدئي هو 1,150 ريال للتدريب الأونلاين المباشر و1,450 ريال للحضور في الرياض. يجب تأكيد السعر النهائي وطريقة الحضور ومحتويات الباقة قبل السداد.

كم مدة الدورة ومتى تبدأ الدفعة القادمة؟

لم تظهر مدة أو دفعة مؤكدة في المحتوى الحالي. الموعد يحدد بحسب الدفعات المتاحة، ويجب تأكيد عدد الأيام والساعات والجدول قبل التسجيل.

ما الوظائف التي تستفيد من مهارة Microsoft Project؟

تفيد المهارة مديري المشاريع ومهندسي التخطيط ومنسقي المشاريع وأعضاء PMO ومختصي Project Controls. لكنها لا تضمن وظيفة، وتزداد قيمتها مع فهم إدارة المشاريع والخبرة القطاعية والقدرة على إعداد تقارير موثوقة.
